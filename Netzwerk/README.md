# 🌐 Netzwerk

Ein Smart Home ist vor allem ein **Netzwerk** aus vielen Geräten, die über unterschiedliche Protokolle miteinander sprechen. Dieser Ordner erklärt die Grundlagen, die man für die Arbeit im Labor braucht – praktisch, mit den Werkzeugen, die man täglich einsetzt.
